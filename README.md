# Olist E-Commerce Sales Analysis | Power BI

## Project Overview

This project focuses on analyzing Brazilian e-commerce data using Microsoft Power BI to understand sales performance, customer purchasing behavior, product category trends, order status, and delivery performance.

The objective is to transform raw e-commerce data into meaningful business insights through data cleaning, data modeling, DAX calculations, and interactive dashboards.

## Business Objectives

- Analyze overall e-commerce sales performance.
- Identify top-performing product categories.
- Understand customer purchasing patterns.
- Analyze order status and delivery performance.
- Examine payment method distribution.
- Identify high-performing cities and customer segments.
- Evaluate repeat customer behavior.

## Tools & Technologies

- **Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX** – Calculated measures and business KPIs.
- **Excel** – Initial data preparation and inspection.

## Project Workflow

### 1. Data Preparation
- Imported the Olist e-commerce datasets.
- Inspected missing values, duplicate records, and data inconsistencies.
- Cleaned and transformed data using Excel Power Query.
- Handled missing values based on their business context.

### 2. Data Modeling
- Established relationships between relevant tables.
- Organized the data model to support cross-table analysis.
- Created calculated columns and measures using DAX.

### 3. Dashboard Development
Designed interactive Power BI dashboards to explore different aspects of e-commerce performance.

**Key Analysis Areas:**
- Sales Overview
- Product Category Analysis
- Customer Analysis
- Order and Delivery Performance
- Payment Method Analysis

### 4. Business Insights

The dashboards help explore:
- Sales distribution across product categories.
- Customer purchasing and repeat purchase patterns.
- Order fulfillment and cancellation trends.
- Delivery performance and delays.
- Geographic sales distribution.
- Payment method preferences.
